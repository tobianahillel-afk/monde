# GitHub Agentic Workflows — MONDE Research Note

Status: Draft  
Canonical: No

GitHub agentic workflows may later be useful for non-deterministic repository assistance: issue/PR triage, documentation-drift detection, capability duplicate suggestions, research preparation, incident summaries and periodic maintenance proposals.

They must not be the sole authority for constitutional PASS/FAIL decisions. Deterministic governance, security checks, tests and live merge-state verification remain authoritative gates.

Before adoption, evaluate: preview/stability status, permission model, token/compute cost, reproducibility, audit trail, prompt/context injection risks, behavior on untrusted pull requests, and whether an equivalent deterministic workflow would be simpler.
